# Capturas de repositorios de GitHub

Deja aquí una imagen por repositorio con el **nombre exacto del repo** (sin
extensión):

```
controlGastos.png
Footprint-Mappa.webp
Tron.jpg
```

Formatos admitidos: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`. Se recomienda una
imagen horizontal de al menos 1200 px de ancho.

La sección `/proyectos` la detecta automáticamente (no hay que importar nada).
Si un repo no tiene captura, se usa la imagen social que GitHub genera sola.
